# Student Marks Processing Program

A simple C++ console application that collects student marks and computes basic statistics.

## Features

* **Input Validation:** Accepts a valid number of students between `0` and `100`.
* **Total Mark:** Computes the sum of all entered marks.
* **Average Mark:** Calculates the class average score.
* **Highest & Lowest Marks:** Identifies the maximum and minimum scores in the class.
* **Pass/Fail Count:** Tracks and displays how many students passed and failed.
